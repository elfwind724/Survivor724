# 03 幸存者与工作系统

## NPC 不是派遣后消失

外勤必须走完整条物理过程。以猎人为例：

1. 黎明到装备库领取指定武器、弹药、猎刀和背包
2. 前往食堂领取当天口粮
3. 从大门离开基地
4. 沿安全路线前往狩猎区域
5. 搜索足迹、叫声或活动痕迹
6. 接近目标并判断是否攻击
7. 射击、追踪或躲避
8. 处理猎物，获得肉、皮和骨料
9. 将物资装入实际背包
10. 背包满、弹药不足、受伤或天色将晚时返程
11. 进入基地，把物资放入冷藏库或原料仓
12. 归还公用工具，进入休息、治疗或次要岗位

玩家可以跳转镜头、下令撤退，或直接接管完成战斗。

## 四层分配

### 1. 主要岗位

猎人、渔夫、搜刮者、伐木工、采集者、建筑工、搬运工、厨师、医护、维修工、制作工、守卫。

### 2. 工作优先级

禁止 / 低 / 普通 / 高 / 紧急。机械师主职维修，无损坏时可制作；紧急修门会打断普通制作。

### 3. 工作区域

玩家在地图上绘制或选择允许区域。NPC 只能在允许区域内找目标。

### 4. 行动规则

最低弹药、最低工具耐久、背包返程比例、生命撤退线、遇敌求援阈值、最晚返程时间、卸货仓库。

## 任务由世界生成

不是 NPC 随机决定。厨房缺肉、仓库木材低于安全线、蓝图缺废金属、大门耐久低、伤员等待治疗，都会生成任务。岗位系统按优先级、技能、距离、疲劳、工具和危险容忍度选人。

## 外勤不得作弊

- 没有鱼竿不能钓鱼
- 没有猎刀只能带回完整尸体或少量肉
- 没有弹药不能继续狩猎
- 背包满后不能无限收集
- 仓库已满时无法正常卸货
- 大门关闭或路线被堵必须重新寻路
- 重伤降低移动和工作速度

## 异常事件发生在现有空间上

枪声吸引感染者、猎物逃入危险区、搜刮触发坍塌、搬运途中遇袭丢物资、工具损坏后原地等待或返程。不是随机弹窗给结果。

玩家可选：自行处理、派支援、撤退、镜头接管。

## 人物构成

1. 身份与外观
2. 过去职业
3. 五项基础属性：体魄、协调、感知、智识、意志
4. 可成长技能 0–10：枪械、近战、狩猎、钓鱼、搜刮、建造、维修、制作、烹饪、医疗、领导
5. 两至三个特质，必须明显改变玩法
6. 一个职业招牌能力

不做逐秒饥饿、口渴和上厕所。只保留疲劳、伤势、士气。食物和水以社区供给为主。

## 倒地与永久死亡

生命归零后倒地，有限救援窗口。救援失败则永久死亡，同时失去人物、岗位能力、装备熟练和社区关系。

## 首版职业

垂直切片至少验证：猎人、机械师、急救员、警员，外加通用工人。职业表见源文档第十章。招募必须改变白天生产能力或夜间防御能力。

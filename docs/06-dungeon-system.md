# 06 副本系统

一天一次跑图。副本是 8–12 节点图，不是第二张开放世界。

入口只有主世界废墟附近一座发光山洞。没有地铁、医院、停车场清单。

## 日循环

进洞刷宝 → 对比换枪 → 天黑前撤离 → 用今天的枪守夜。

人、枪、伤势、仓库跨日保留。不是每局删档。

## 节点图

`generateDungeonLayout(dayIndex, worldSeed)` 出图。同样输入同样结果。

- 长度 8–12
- 第一间 combat
- 最后一间 exit
- 中间按权重抽：combat 50 / event 20 / reward 15 / elite 10
- exit 只出现在最后
- elite luck = 0.08，exit luck = 0.15，其余 0

种类只有五种：combat / event / reward / elite / exit。

## 房间三选

`rollRoomPicks` 给出 3 个不重复选项：弹药、绷带、装备箱、神龛。

装进真实背包。不自动进仓库。带不走就留在洞里。

## 对比换枪

C 开人物面板，对比哪把枪更强，换上再走。夜里用这把枪守。

## 撤离

走到 exit 出本。天黑前必须出来。没出来，今夜失去实时指挥。

## 外部世界

进本后全局时钟继续。主世界 NPC 继续干活。带进洞的是现有幸存者，不另造探险角色。

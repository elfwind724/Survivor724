# 05 夜间防守

## 玩家负责指挥，不是替所有人射击

NPC 低层动作：到岗、搜索射界、瞄准射击、换弹、就近补给、危险阈值撤退、执行已分配的维修救援运输。

玩家高层决策：哪个方向优先、哪里增援、是否放弃外墙退二线、哪类敌人集火、何时全力耗弹、维修队是否冒险修门、医疗队去哪救人、何时亲自接管。

## 防御分区

北墙、东门、南墙、西侧设施区、内层核心区。每区有岗位、人数、火力、弹药、墙门状态、敌人压力、撤退点、支援请求。点击分区下令，不逐个找人。

## 夜间角色

| 角色 | 职责 |
|---|---|
| 岗哨射手 | 固定射界，自动打入界目标，缺弹呼叫补给 |
| 精确射手 | 优先特殊敌人，节省弹药 |
| 重武器手 | 固定机枪等，管理过热和弹药箱，适合第一人称接管 |
| 维修队 | 安全阈值内修门墙炮塔，敌人靠近则撤，可一次高风险紧急加固 |
| 医疗队 | 二线救护，治疗轻伤，接令拖回倒地者 |
| 弹药搬运员 | 从军械库送到前线箱，路线被突破会改道 |
| 机动预备队 | 核心区待命，增援最危险方向，封缺口 |
| 指挥员 | 提高附近响应、士气和命令执行，必须实际靠近战线 |

前线弹药箱可以被打空或摧毁。岗哨没有无限弹药。

## 三层命令

**全局：** 弹药策略、防御姿态、照明、大门、撤退阈值。

**分区：** 坚守、增援、集火、优先保护大门、维修优先、撤二线、封锁、启用陷阱。

**单位：** 移动、占岗、技能、救援、维修、搬运弹药、换武器、立即撤退。

基础命令不消耗魔法指挥点。少数强力行动可有冷却或稀缺物资消耗。

## 第一人称是战术接管

选中任意幸存者后进入第一人称：精准打弱点、操纵重武器、破口近战、亲自修门、拖拽队友。接管期间该角色暂停自动决策；退出后恢复原岗位。

第一人称不另做独立伤害、武器和背包。停留过久，其他方向可能失守。

## 夜战节奏

1. 预兆：远处声音、探照灯发现零散敌人
2. 试探：少量敌人测试外墙
3. 主攻：两方向持续压力
4. 危机：特殊敌人、停电、破口或迟归接近大门
5. 终局：精英或首领后敌群逐渐退去，不是突然消失

## 破墙之后仍可打

至少三层空间：外围减速与陷阱、外墙与主火力、内层生活与核心。

墙破后敌人从真实缺口进入，流场必须更新。预备队赶往缺口，维修队可临时封堵，玩家可关内门放弃局部。只有指挥核心被毁、全员死亡或社区失去生存能力才判负。

## 首版敌人

先做四种以验证战术差异：游荡者、奔袭者、攀爬者、破墙者。尖啸者、喷吐者、潜伏者后扩。

夜间威胁由可理解因素构成：天数成长、人口、噪声、灯光广播、未清理巢穴，减去侦察与区域控制。玩家能看到大致来源。

普通敌群用流场趋向噪声、入口和薄弱区。普通枪械优先射线命中。

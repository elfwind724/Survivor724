# 《黎明据点 / Dawn Bastion》
## 玩法详细设计与 Three.js 开发报告 v2.0

> 本版本对 v1.0 作根本修正：
>
> 白天不是“派出队伍后等待随机结算”，也不是“基地阶段结束后再进入远征阶段”。基地、幸存者、野外资源点、废墟和玩家探索同时存在于一个持续运行的世界中。幸存者会真实离开基地，沿路线前往森林、河岸和废墟，使用工具工作，把实际获得的物资装进背包，再亲自带回仓库。玩家可以随时观察、下令、跟随或接管其中任何一人。
>
> 独立山洞、地下设施和大型建筑内部可以作为副本加载，但副本期间全局时钟、基地生产、外勤 NPC 和夜晚威胁仍继续运行。

---

# 一、重新定义这款游戏

## 1.1 类型定位

**3D 俯视动作指挥 × 活体聚落经营 × 昼夜攻防 × 幸存者收集培养 × 第一人称战术接管。**

它不是单纯的“带建造的吸血鬼幸存者”，也不是传统殖民模拟，更不是把两个互不相干的俯视游戏与 FPS 强行拼接。

真正的游戏核心是：

**玩家领导的是一个活着的幸存者共同体。每一个人白天都在世界中真实工作，夜晚都在基地中真实作战；玩家负责制定计划、处理例外，并在最危险的时刻亲自接管。**

## 1.2 四个核心动词

1. **建造**：设计基地结构、生活设施、生产链和防御纵深。
2. **分配**：决定每名幸存者白天做什么、在哪里做、何时返回，夜晚守哪里、执行何种战术。
3. **探索**：亲自带队进入废墟、山洞和地下设施，获得普通 NPC 无法安全取得的高价值资源、蓝图和幸存者。
4. **指挥**：夜晚不必替每名 NPC 扣扳机，而是观察战线、调动预备队、改变火力优先级、组织维修与救援，并在关键位置接管一名幸存者战斗。

## 1.3 游戏最重要的差异化

### 每一个幸存者都是同一个持续存在的实体

同一个人拥有：

- 白天工作岗位。
- 外勤路线和实际背包。
- 夜间战位。
- 武器、弹药和装备。
- 等级、技能、伤势、疲劳与士气。
- 可被玩家俯视操控或第一人称接管的身体。

不存在“工作界面里的工人”“夜战界面里的士兵”“副本里的英雄”三套互不相干的数据。

### 玩家管理规则，不管理每一个动作

玩家不需要命令猎人走到每一棵树旁，也不需要命令厨师切每一块肉。玩家下达的是：

- 谁负责狩猎。
- 狩猎区域在哪里。
- 使用什么装备。
- 遇到多大危险时撤退。
- 最晚几点返回。
- 猎物送到哪个仓库或屠宰间。

NPC 自己完成移动、寻找目标、工作、战斗、装载和返程。出现危险、道路阻断、工具损坏、背包已满或天色将晚时，再由玩家处理例外。

# 二、不可妥协的设计原则

1. 基地与周边野外属于同一张持续运行的主世界。
2. 白天所有生产、建设、外勤和玩家探索同步发生，不拆成互斥阶段。
3. NPC 的野外收集必须有真实目标、路线、工具、工作动作、背包和返程，不使用“派遣后抽取奖励”的主循环。
4. 独立副本可以加载，但副本外的世界继续运行。
5. 夜晚 NPC 能够自主找到岗位、选择目标、换弹、撤退、补给、救援和维修；玩家负责战术而不是替所有人逐个操作。
6. 俯视与第一人称共享同一人物、同一武器、同一弹药和同一伤害模型。
7. 招募一名幸存者必须同时改变生产能力、探索能力或防御能力，不能只是人口数字增加。
8. 基地第一次破墙不能立即判负。内层防线、撤退路线、维修队和预备队必须有意义。
9. 复杂度首先用“规则与岗位”表达，不用几十种琐碎需求堆叠。
10. 第一版必须先证明“活体聚落 + 白天真实外勤 + 夜晚指挥防守”成立，再扩展车辆、派系、天气和大型剧情。

# 三、世界空间结构

## 3.1 主世界不是开放世界，而是高密度持续区域

推荐首版主世界约为 320×320 米至 450×450 米的可活动区域，中央或偏中央为基地，四周分布可重复工作的资源区和有限数量的关键地点。

地图分为四层：

### 基地核心区

- 指挥中心。
- 生活与生产建筑。
- 仓库与道路。
- 外墙、内墙、大门和岗哨。
- 夜晚主要防御空间。

### 日常作业圈

距离基地较近，普通幸存者可以独立前往：

- 河岸与鱼点。
- 小型林地。
- 野果和药草区。
- 低风险废墟。
- 石料、木料和废金属点。

### 危险作业圈

需要武装人员或小队：

- 大型废墟。
- 感染者巢穴。
- 高价值车辆残骸。
- 野兽活动区。
- 敌对幸存者哨点。

### 副本入口圈

主世界中可见的入口，进入后加载独立内部空间：

- 山洞。
- 地下停车场。
- 地铁站。
- 医院内部。
- 军事掩体。
- 工厂地下层。

## 3.2 资源点是持续对象，不是菜单按钮

每个资源点都记录：

- 位置。
- 当前储量。
- 资源类型。
- 危险等级。
- 工作容量。
- 所需工具。
- 是否被侦察。
- 是否存在感染、坍塌、陷阱或野兽。
- 再生或枯竭规则。

森林会逐步减少可砍伐树木；废墟被搜空后只剩低价值材料；鱼点在短时间过度捕捞后产量下降；野兽会迁移而不是固定刷新在同一点。

## 3.3 视野与信息

玩家不应一开始知道所有资源和敌人位置。

信息来源包括：

- 幸存者实际经过并观察。
- 岗哨视野。
- 侦察员巡逻。
- 无人机或望远镜等后期设施。
- 广播与幸存者情报。

已侦察区域显示资源类型和大致风险；未侦察区域只显示地形轮廓。

# 四、一个完整昼夜循环

## 4.1 建议基准时长

首个可玩版本建议一个完整游戏日约 20 分钟：

- 黎明整备：1 分钟。
- 有效白昼：11 分钟。
- 黄昏返程：1 分 30 秒。
- 夜间防守：5 分 30 秒至 6 分 30 秒。
- 战后处理：1 分钟。

这不是最终数值，但必须保证白天有明确期限，夜晚足够激烈，同时一轮不会拖成四十分钟的经营局。

## 4.2 白天不是独立菜单阶段

黎明后，全体幸存者根据当天计划同时开始行动：

- 猎人去林区。
- 渔夫去河岸。
- 搜刮者去废墟。
- 建筑工搬运材料并建造。
- 厨师处理昨天带回的食材。
- 机械师维修夜间受损设施。
- 医护人员治疗伤员。
- 玩家检查基地后，可随时带队外出或进入副本。

所有活动共用同一个时钟。

## 4.3 时间速度

- 正常行动：1×。
- 玩家处于基地俯视管理、附近无战斗且没有紧急事件时：可切换 2×。
- 玩家直接控制人物、进入副本或发生战斗时：自动恢复 1×。
- 不建议首版提供 4×，否则真实 NPC 行动会退化成数字跳动，玩家也难以形成对每个人的观察与感情。

## 4.4 三次黄昏警告

- 白昼剩余 30%：指挥中心第一次提醒，远距离 NPC 开始评估返程。
- 剩余 15%：第二次提醒，默认完成当前动作后返回。
- 剩余 5%：基地警报，除“坚守外勤”命令外全部人员立即返程。

玩家可以为每个岗位设定不同的返程规则，但迟归必须有真实代价。

# 五、白天 NPC 工作系统

## 5.1 四层分配结构

### 第一层：主要岗位

决定此人通常从事哪一类工作：

- 猎人。
- 渔夫。
- 搜刮者。
- 伐木工。
- 采集者。
- 建筑工。
- 搬运工。
- 厨师。
- 医护。
- 维修工。
- 制作工。
- 守卫。

### 第二层：工作优先级

每名幸存者可以给若干工作设置：

- 禁止。
- 低。
- 普通。
- 高。
- 紧急。

例如机械师主职维修，但没有损坏设施时，可以承担装备制作；紧急修门时，系统会打断普通制作。

### 第三层：工作区域

玩家在地图上绘制或选择工作区域：

- 北部森林狩猎区。
- 东侧河岸捕鱼区。
- 南部废墟搜刮区。
- 基地内部搬运区。
- 禁止进入的感染区。

NPC 只能在允许区域寻找目标，避免他们为了一个资源点走到地图另一端。

### 第四层：行动规则

每个外勤岗位可以保存规则：

- 最低携带弹药。
- 最低工具耐久。
- 背包达到多少比例返程。
- 生命低于多少撤退。
- 遇到几只感染者时请求支援。
- 最晚返程时间。
- 物资送往哪个仓库。

## 5.2 NPC 一次完整工作的真实流程

以猎人为例：

1. 黎明到装备库领取指定武器、弹药、猎刀和背包。
2. 前往食堂领取当天口粮。
3. 从大门离开基地。
4. 沿安全路线前往狩猎区域。
5. 搜索足迹、叫声或活动痕迹。
6. 接近目标并判断是否攻击。
7. 射击、追踪受伤猎物或躲避危险。
8. 对猎物进行处理，获得肉、皮和骨料。
9. 将物资装入实际背包。
10. 背包满、弹药不足、受伤或天色将晚时返程。
11. 进入基地，将物资放入冷藏库或原料仓。
12. 归还公用工具，进入休息、治疗或次要岗位。

整个过程都发生在世界中。玩家可以点击头像跳转镜头，可以在遭遇危险时下令撤退，也可以直接接管猎人完成战斗。

## 5.3 工作任务如何产生

任务不是由 NPC 随机决定，而由世界和设施生成。

例如：

- 厨房缺少原料，生成“取得肉类”需求。
- 仓库木材低于安全线，生成“伐木”需求。
- 新围墙蓝图需要 30 单位废金属，生成“搜刮金属”需求。
- 大门耐久低，生成“维修大门”紧急任务。
- 伤员等待治疗，生成“医务室治疗”任务。

岗位系统根据优先级、技能、距离、疲劳、工具和危险容忍度选择合适的人。

## 5.4 外勤 NPC 不会作弊

NPC 必须满足真实条件：

- 没有鱼竿不能钓鱼。
- 没有猎刀只能带回完整尸体或少量肉。
- 没有弹药不能继续狩猎。
- 背包满后不能继续无限收集。
- 仓库已满时无法正常卸货。
- 大门关闭或路线被围墙堵死时必须重新寻路。
- 受重伤时会降低移动和工作速度。

这使基地设施、工具制作、道路设计和仓库位置真正进入玩法。

## 5.5 工作中的异常事件

异常事件不是“随机弹窗给结果”，而是在现有空间和状态上发生：

- 枪声吸引附近感染者。
- 猎物受伤后逃入危险区。
- 搜刮者触发坍塌，出口被阻挡。
- 渔夫发现漂浮尸体或特殊箱子。
- 搬运工途中被敌人袭击并丢下物资。
- 维修工需要玩家先清理正在攻击墙体的敌人。
- NPC 工具损坏后在原地等待、改做徒手低效工作或返程。

玩家收到地图警报后可以选择：

- 让 NPC 自行处理。
- 派附近幸存者支援。
- 下令撤退。
- 切换镜头并亲自接管。

# 六、白天外勤玩法细化

## 6.1 狩猎

### 核心目标

狩猎不是点击资源点读条，而是低烈度、带突发危险的动态活动。

### 动物行为

- 鹿类：警觉高，发现人后逃跑，适合远程精准射击。
- 野猪：受伤后可能冲锋，肉量大但危险。
- 小型动物：产量低，噪声小，适合缺弹药时使用陷阱。
- 掠食动物：可能主动袭击孤立 NPC。

### 猎人能力影响

- 发现踪迹的距离。
- 接近时惊动概率。
- 射击弱点能力。
- 追踪受伤猎物速度。
- 屠宰产量。
- 对危险动物的判断。

### 狩猎工具

- 猎枪或步枪。
- 弓弩或消音武器，后期降低噪声。
- 猎刀。
- 陷阱。
- 大背包或拖拽架。

### 产生的资源

- 生肉。
- 兽皮。
- 骨料。
- 少量脂肪或特殊材料。

枪声会提高局部噪声值，因此高产狩猎可能让夜间某一方向的威胁增加。

## 6.2 钓鱼

### 鱼点类型

- 河岸浅水点：安全、产量低。
- 深水点：产量高，需要更好鱼竿或渔网。
- 污染水域：可能获得变异鱼、化学材料或疾病风险。
- 隐蔽水湾：距离远，较少感染者，但返程时间长。

### 钓鱼方式

- 鱼竿：单人、低成本、较慢。
- 渔网：需要制作和维护，可由两人操作，产量高。
- 捕鱼笼：布置后隔一段时间收取，可能被破坏。

### NPC 行为

渔夫到达鱼点后选择位置、放置工具、等待、收取并装箱。因长时间静止，渔夫比猎人更容易遭到偷袭，因此附近岗哨、巡逻路线或护卫会有价值。

### 产出

- 鲜鱼。
- 鱼油或骨料。
- 极低概率取得水下废弃物、钥匙或特殊线索。

鱼需要尽快送入厨房、烟熏房或冷藏库，否则会腐坏。

## 6.3 废墟搜刮

废墟分两类。

### 浅层废墟

与主世界无缝存在，NPC 可以自主搜索：

- 倒塌民房。
- 路边商店。
- 废弃车辆。
- 小型仓库。
- 建筑外部残骸。

NPC 的实际流程：清理周边威胁 → 检查入口 → 搜索容器 → 拆取材料 → 装入背包 → 标记已搜区域 → 返程。

### 深层地点

需要玩家亲自带队，进入独立副本：

- 山洞。
- 医院内部。
- 地下设施。
- 大型超市深处。
- 军事掩体。

普通 NPC 不会自动完成这些地点，只能在玩家已经清理并建立安全标记后承担后续搬运。

### 搜刮者技能影响

- 发现隐藏容器。
- 搜索速度。
- 判断建筑稳定性。
- 开锁与拆卸能力。
- 重物搬运效率。
- 识别陷阱和感染痕迹。

### 重型物资

发电机、金属箱、机械部件等不能直接变成背包数字，需要：

- 两人搬运。
- 推车。
- 后期车辆。
- 先标记，再派搬运队。

## 6.4 伐木、采集与拆解

为了让建设资源也来自真实世界，首版可保留三种简单外勤：

- 伐木：获得木材，产生较高噪声。
- 野外采集：获得野果、草药、纤维。
- 拆解残骸：获得废金属和零件。

这些岗位不需要像狩猎一样复杂，但同样遵循“前往—工作—装载—返程—卸货”的物理过程。

## 6.5 玩家为什么还需要亲自外出

自动工作的 NPC 负责稳定资源，玩家外出负责高价值和高风险内容：

- 清除危险区域。
- 取得蓝图、武器和稀有部件。
- 救援幸存者。
- 击杀精英敌人。
- 开启新的资源区。
- 进入副本。
- 处理 NPC 无法解决的突发危机。

因此自动化不会取代玩家，而是把重复劳动交给社区，让玩家专注于决策和突破。

# 七、玩家白天探索与副本系统

## 7.1 出发前组队

玩家从幸存者中选择 1 至 4 人组成探索小队。

需要决定：

- 队长。
- 携带武器和弹药。
- 医疗物资。
- 工具。
- 背包容量。
- 是否携带爆破、照明或开锁装备。
- 预计返回时间。

组队不是另造一批“探险角色”，而是暂时把这些真实居民从原有岗位抽走。

带走机械师意味着基地白天维修变慢；带走狙击手意味着当晚岗哨可能缺少核心火力；带走医生则提高副本生存率，但基地伤员恢复暂停。

## 7.2 主世界探索

玩家在俯视视角下控制当前队长，其他成员以编队 AI 跟随。

基础命令：

- 跟随。
- 原地警戒。
- 分散搜索。
- 集中到标记点。
- 优先攻击指定目标。
- 停火。
- 撤退。
- 搬运指定物品。

玩家可在小队成员之间切换，也可对选定成员进入第一人称。

## 7.3 进入山洞或内部副本

入口存在于主世界。玩家到达后确认进入，加载独立内部场景。

进入时记录：

- 进入时间。
- 小队成员。
- 每人装备、伤势、疲劳和背包。
- 副本外入口周边威胁。
- 基地当前计划。

副本内部不生成“额外副本角色”。所有伤害、弹药、拾取和死亡直接作用于原人物。

## 7.4 副本期间外部世界如何运行

全局时钟继续。

主世界不必继续完整渲染，但模拟层继续处理：

- NPC 沿已确定路线移动。
- 外勤工作推进。
- 资源装入实际背包。
- 建造与制作推进。
- 受伤、攻击、撤退和返程。
- 黄昏警报。
- 基地岗位切换。

这不是随机远征结算，而是对同一实体状态的低频确定性模拟。

## 7.5 副本与夜晚的硬关系

默认设计：山洞和深层地下设施中无线电信号受限。

- 玩家在副本内只能切换本小队成员。
- 无法直接切回基地进行完整夜战指挥。
- 黄昏前必须决定继续深入还是撤离。
- 若夜晚到来仍未离开，基地按预设防御方案自主作战，玩家失去实时战术指挥优势。
- 副本内夜晚敌人可能更活跃，出口周围也可能被感染者占据。

这使“白天限定时间内完成”不是UI倒计时，而是与基地生死直接相连的战略压力。

后期可以通过可携带中继器、已清理安全屋或高等级无线电，有限解除这一限制，但不能在首版中抹平时间压力。

## 7.6 副本获得物不会自动结算

玩家必须：

- 把物品装进具体成员背包。
- 在负重、弹药和医疗之间取舍。
- 将重型物资标记，之后派搬运队。
- 从入口真实撤离。
- 返回基地后将物资卸入仓库。

没有“完成任务后奖励自动进入总库存”。

# 八、黄昏返程系统

## 8.1 自动返程不是传送

黄昏时，NPC 根据路线距离和移动速度计算是否能按时回到基地。

地图显示：

- 绿色：预计安全返回。
- 黄色：可能迟到。
- 红色：无法在夜幕前到达。

玩家可以下达：

- 立即返程。
- 完成当前工作后返程。
- 丢弃部分负重快速返程。
- 前往最近安全屋过夜。
- 请求护卫接应。
- 坚持工作，接受夜间风险。

## 8.2 迟归人员

迟归不会瞬间死亡，也不会自动传回。

他们会：

- 尝试沿已知安全路线回基地。
- 遇敌时躲避、战斗或求援。
- 有安全屋时就近躲藏。
- 携带重物时可能丢弃负重逃生。
- 受到疲劳、恐惧和视野惩罚。

玩家可以选择接管他们，也可以让基地继续按预案防守。

## 8.3 黄昏战备切换

返回基地的居民自动执行“战备流程”：

1. 卸下采集物。
2. 补充弹药和医疗品。
3. 更换夜战武器或护甲。
4. 前往夜间战位。
5. 维修队检查重点结构。
6. 医护人员建立救护点。
7. 弹药搬运员填充前线弹药箱。
8. 大门按计划关闭。

玩家不必每天重复拖动所有人，但可以修改任何异常安排。

# 九、夜间防守：玩家真正负责的是指挥

## 9.1 夜晚不是纯自动挂机

NPC 负责低层动作：

- 移动到岗位。
- 搜索射界内目标。
- 瞄准和射击。
- 换弹。
- 就近补给。
- 在危险阈值下撤退。
- 执行已分配的维修、救援和运输。

玩家负责高层决策：

- 哪个方向优先防守。
- 哪个区域需要增援。
- 是否放弃外墙并退到第二道防线。
- 哪类敌人需要集火。
- 何时允许全力消耗弹药。
- 维修队是否冒险修门。
- 医疗队去哪里救人。
- 何时亲自接管关键幸存者。

## 9.2 防御分区

基地被划分为若干防御区：

- 北墙。
- 东门。
- 南墙。
- 西侧设施区。
- 内层核心区。

每个区拥有：

- 防御岗位。
- 当前人数。
- 火力评分。
- 弹药余量。
- 墙体与大门状态。
- 当前敌人压力。
- 撤退点。
- 支援请求。

玩家点击分区即可查看和下令，不需要逐个寻找角色。

## 9.3 夜间角色

### 岗哨射手

- 占据墙体、塔楼或射击平台。
- 维持固定射界。
- 自动选择进入射界的目标。
- 弹药不足时呼叫补给。

### 精确射手

- 优先攻击尖啸者、喷吐者、破墙者等特殊敌人。
- 默认节省弹药，不对最弱敌人连续射击。

### 重武器手

- 操纵固定机枪、榴弹发射器或后期重武器。
- 管理过热和弹药箱。
- 适合玩家第一人称接管。

### 维修队

- 在安全阈值内修复门、墙、炮塔和发电机。
- 敌人靠近时停止维修并撤到掩体。
- 可执行一次高风险“紧急加固”。

### 医疗队

- 留在二线救护点。
- 自动治疗轻伤。
- 接到救援命令后前往拖回倒地者。

### 弹药搬运员

- 从军械库或仓库把弹药送到前线箱。
- 路线被突破时会改道。
- 这一岗位决定持续火力，而不是让岗哨拥有无限弹药。

### 机动预备队

- 平时留在核心区。
- 根据玩家命令或预设阈值增援最危险方向。
- 负责封堵突破口、救援和反冲锋。

### 指挥员

- 提高附近人员响应速度、士气和命令执行效率。
- 不是单纯全图加成，需要实际处于战线附近。

## 9.4 三层命令系统

### 全局命令

- 弹药策略：节省 / 平衡 / 全力。
- 防御姿态：坚守外墙 / 弹性防御 / 保护核心。
- 照明策略：节能 / 重点照明 / 全开。
- 大门策略：自动开闭 / 永久关闭 / 接应迟归人员。
- 撤退阈值：墙体低于多少、敌人进入多近时撤退。

### 分区命令

- 坚守该区。
- 增援该区。
- 集火特殊目标。
- 优先保护大门。
- 维修优先。
- 撤至第二防线。
- 封锁通道。
- 启用陷阱。

### 单位命令

- 移动到点。
- 占据岗位。
- 使用职业技能。
- 救援指定队友。
- 维修指定设施。
- 搬运弹药。
- 更换武器。
- 立即撤退。

基础命令不消耗人为设置的“魔法指挥点”。少数强力行动可以有冷却或消耗稀缺物资，例如迫击炮齐射、紧急照明、广播鼓舞和全区撤退烟幕。

## 9.5 战术慢速

玩家打开命令模式时，时间可降至 25%—35%，但不完全暂停。

原因：

- 保留战斗压力。
- 给玩家足够时间观察和下令。
- 防止夜战变成纯 RTS 菜单操作。

简单难度可以允许完全暂停下令，标准难度使用慢速。

## 9.6 第一人称战术接管

玩家选中任意幸存者后进入第一人称：

- 手动精准瞄准弱点。
- 操纵重武器。
- 在破口处近距离作战。
- 亲自维修大门。
- 拖拽倒地队友。
- 投掷手雷或布置临时障碍。

接管期间，该角色暂停自动决策；退出后恢复其原岗位和命令。

第一人称不是更高等级的模式，而是牺牲全局视野换取局部效率。玩家在第一人称停留过久，其他方向可能失守。

## 9.7 夜战节奏

建议一场普通夜战分为五段：

1. **预兆**：远处声音、探照灯发现零散敌人，玩家确认来袭方向。
2. **试探**：少量敌人测试外墙和岗哨，给玩家最后调整机会。
3. **主攻**：两个方向形成持续压力，普通敌群消耗弹药和墙体。
4. **危机**：特殊敌人、停电、破口或迟归人员接近大门，迫使玩家选择优先级。
5. **终局**：精英或首领出现，击败后敌群逐渐退去，而不是突然全部消失。

## 9.8 破墙之后仍可继续战斗

基地至少拥有三层空间：

- 外围减速与陷阱区。
- 外墙与主要火力区。
- 内层生活区和核心防线。

墙体破坏后：

- 敌人从真实缺口进入。
- 预备队赶往缺口。
- 维修队可在火力掩护下临时封堵。
- 玩家可关闭内门，放弃局部区域。
- 被占领的设施可能停产、起火或损坏。

只有指挥核心被彻底摧毁、所有幸存者死亡或社区失去继续生存的能力时才判负。

# 十、幸存者系统

## 10.1 人物构成

每名幸存者由六个层次组成：

1. 身份与外观。
2. 过去职业。
3. 五项基础属性。
4. 若干可成长技能。
5. 两至三个特质。
6. 一个职业招牌能力。

## 10.2 五项基础属性

### 体魄

影响生命、负重、近战、拖拽和重武器使用。

### 协调

影响移动、换弹、武器操控、工作动作和闪避。

### 感知

影响视野、射击、发现踪迹、搜刮与危险预警。

### 智识

影响维修、制作、医疗、学习和复杂设施效率。

### 意志

影响士气、夜战稳定、受伤后的表现和恐慌抵抗。

## 10.3 专业技能

技能通过实际使用成长，并在升级时获得少量定向强化：

- 枪械。
- 近战。
- 狩猎。
- 钓鱼。
- 搜刮。
- 建造。
- 维修。
- 制作。
- 烹饪。
- 医疗。
- 领导。

不需要把每项细分成几十级。首版每项 0—10 级已足够形成差异。

## 10.4 职业样例

| 职业 | 白天优势 | 夜间优势 | 初始武器 | 招牌能力 |
|---|---|---|---|---|
| 退伍军人 | 训练其他居民 | 压制与稳定战线 | 突击步枪 | 压制射击 |
| 猎人 | 追踪、狩猎、屠宰 | 标记精英弱点 | 栓动步枪 | 猎杀标记 |
| 渔夫 | 捕鱼和水域资源 | 高意志、低光稳定 | 旧式霰弹枪 | 稳住阵脚 |
| 警员 | 搜查与警戒 | 近中距离控场 | 手枪或冲锋枪 | 战术喝止/击退 |
| 急救员 | 治疗与感染控制 | 快速救援倒地者 | 紧凑手枪 | 战地急救 |
| 机械师 | 修理设施与装备 | 紧急修门、炮塔 | 冲锋枪 | 临时加固 |
| 电工 | 发电、照明、电网 | 电力过载控群 | 左轮手枪 | 电网过载 |
| 厨师 | 食物利用和强化餐 | 提升附近士气 | 短霰弹枪 | 战前热餐 |
| 木匠 | 建筑速度和木结构 | 快速建造临时路障 | 手枪 | 现场封堵 |
| 消防员 | 结构安全和灭火 | 拖拽、破障、抗火 | 消防斧 | 强行救援 |
| 搜刮专家 | 开锁、拆解、负重 | 陷阱与临时装置 | 自制手枪 | 快速拆取 |
| 教师/组织者 | 学习、训练、士气 | 提高命令执行 | 手枪 | 集体鼓舞 |

## 10.5 特质必须明显改变玩法

正面特质：

- 夜猫子：夜间反应和工作效率提高。
- 轻脚：移动噪声更低，适合搜刮。
- 冷静：附近队友倒地时不易恐慌。
- 大力士：负重与拖拽能力大幅提高。
- 节俭：制作有概率节省材料。
- 守家者：在基地范围内战斗更稳定。

负面特质：

- 枪声创伤：持续重武器声会积累压力。
- 慢性病：需要稳定药品。
- 鲁莽：遇敌时较晚撤退，杀伤高但风险大。
- 怕黑：无照明时感知和意志下降。
- 独行：与大队行动效率低，但单人侦察更好。
- 嗜睡：黎明出勤慢，夜班表现差。

强力幸存者可以同时带有显著负担，避免形成简单的白、蓝、紫、金稀有度阶梯。

## 10.6 成长结构

### 人物等级

每级提供少量基础属性点或生命、负重等稳定提升。

### 技能成长

实际做什么就提升什么：

- 狩猎提高狩猎技能。
- 守岗射击提高枪械技能。
- 修门提高维修技能。
- 下副本搜刮提高搜刮技能。

### 职业分支

每个职业只需两到三条清晰分支。

例如机械师：

- 生产专家：提高装备与零件制作。
- 战地维修：提高夜间紧急维修。
- 电机技师：强化发电机和自动炮塔。

### 装备强化

- 主武器。
- 副武器。
- 近战或工具。
- 护甲。
- 背包。
- 两个实用装备槽。

武器强弱由品质、状态、配件和人物熟练共同决定，不用单纯追求颜色等级。

## 10.7 疲劳、伤势与士气

为了保持节奏直接，不做逐秒饥饿、口渴和上厕所模拟。

保留三种真正影响决策的状态：

- 疲劳：长时间外勤、夜战和重伤积累。
- 伤势：降低属性，需要医务室和时间恢复。
- 士气：影响命令响应、恐慌和工作效率。

食物和水以社区供给为主，在用餐时影响全体恢复，而不是每个人不断弹出需求。

## 10.8 倒地与永久死亡

- 生命归零后进入倒地。
- 有有限救援窗口。
- 敌人可攻击倒地者，特殊敌人可执行致命动作。
- 队友可以拖回掩体。
- 医护能快速稳定伤势。
- 救援失败则永久死亡。

死亡意味着同时失去人物、岗位能力、装备熟练和社区关系，而不是几秒后重新生成。

# 十一、基地设施完整设计

所有设施必须具备实际空间、岗位槽、输入、输出、工作动作和受损后果。

## 11.1 核心与生活设施

| 设施 | 岗位 | 主要功能 | 夜间价值 |
|---|---|---|---|
| 指挥中心 | 指挥员、无线电员 | 时间计划、人员分配、防御预案 | 提高命令响应，损坏后指挥受限 |
| 宿舍 | 无固定岗位 | 床位、疲劳恢复 | 被破坏会降低战后恢复与士气 |
| 食堂 | 厨师、服务人员 | 集中用餐、士气恢复 | 可在战前提供全体强化餐 |
| 厨房 | 厨师 | 把肉、鱼、植物加工为餐食 | 影响次日恢复和持续作战能力 |
| 医务室 | 医护 | 治疗、稳定伤势、控制感染 | 夜战二线救护点 |
| 休息室 | 无或管理员 | 士气、冲突缓解 | 可作为内层避难空间 |
| 水处理间 | 维修/操作员 | 净水和供水容量 | 停水影响医疗与恢复 |

## 11.2 仓储与物流

| 设施 | 岗位 | 主要功能 | 设计意义 |
|---|---|---|---|
| 综合仓库 | 搬运工 | 木材、废料、普通物资 | 位置决定搬运距离 |
| 冷藏库 | 搬运工 | 肉、鱼、药品保鲜 | 需要电力，停电会腐坏 |
| 军械库 | 军械管理员 | 武器、弹药、护甲 | 夜战补给核心，位置过远会断火力 |
| 前线弹药箱 | 弹药搬运员 | 局部弹药缓存 | 可被摧毁或打空 |
| 工具库 | 管理员 | 鱼竿、猎刀、锤、撬棍等 | NPC 出勤前真实领取工具 |
| 重物堆场 | 搬运工 | 发电机、机械部件、大型材料 | 后期车辆与搬运队接口 |

## 11.3 生产设施

| 设施 | 岗位 | 输入 | 输出 |
|---|---|---|---|
| 维修工坊 | 机械师 | 废金属、零件 | 修理武器、工具、设施部件 |
| 熔炉 | 冶炼工 | 废金属、燃料 | 金属锭与结构件 |
| 装备制作房 | 制作工 | 金属、零件、布料 | 武器部件、护甲、背包 |
| 弹药工作间 | 军械工 | 金属、火药、弹壳 | 各类弹药 |
| 木工间 | 木匠 | 木材、零件 | 墙板、家具、路障、弩类 |
| 屠宰/烟熏房 | 猎人、厨师 | 猎物、鱼、燃料 | 肉类处理、长期食物 |
| 缝纫间 | 制作工 | 布料、皮革 | 服装、护具、背包 |
| 发电机房 | 电工、机械师 | 燃料、零件 | 电力容量 |
| 太阳能/风力设施 | 电工 | 设备部件 | 低维护电力，受天气与损坏影响 |

## 11.4 外勤支持设施

| 设施 | 岗位 | 功能 |
|---|---|---|
| 猎人小屋 | 猎人 | 保存狩猎区域、陷阱、猎具和肉类初处理 |
| 捕鱼码头 | 渔夫 | 提高鱼点容量，部署渔网与捕鱼笼 |
| 搜刮者站 | 搜刮者 | 管理目标废墟、推车和拆解工具 |
| 侦察塔 | 侦察员 | 扩大视野、提前发现夜间来袭方向 |
| 安全屋 | 无常驻或少量守卫 | 外勤人员夜间避难、临时存放物资 |
| 集结点 | 无 | 小队出发、返程和护卫接应位置 |

## 11.5 防御设施

| 设施 | 岗位 | 功能 |
|---|---|---|
| 围墙 | 无 | 阻挡、引导敌群，分木、铁、加固等级 |
| 大门 | 门卫或维修队 | 人员通行和主要防线，必须可手动开关 |
| 射击平台 | 射手 | 提供高度、射界和掩护 |
| 岗哨塔 | 射手/侦察员 | 远距视野和精确射击 |
| 固定机枪位 | 重武器手 | 高持续火力，消耗大量弹药并可能过热 |
| 探照灯 | 电工或自动 | 揭示目标、提高命中、吸引部分敌人 |
| 铁丝网 | 无 | 减速并改变敌人路径 |
| 路障 | 无 | 临时封堵，易建易毁 |
| 电网门 | 电工 | 短时控制突破口，消耗高电力 |
| 燃烧陷阱 | 无或操作员 | 区域杀伤，存在火灾风险 |
| 内层安全门 | 门卫 | 外墙失守后的第二道防线 |
| 战地救护点 | 医护 | 夜战临时治疗与拖拽终点 |

## 11.6 设施不能只是“每小时 +5”

以厨房为例：

- 没有厨师：只能保存少量生食，不能稳定供餐。
- 普通人员：能做基础餐，但浪费原料。
- 专业厨师：提高产量，解锁强化餐。
- 没有清水：产量下降并有疾病风险。
- 没有冷藏：原料逐步腐坏。
- 夜晚被突破：厨房可能起火，次日全体恢复受影响。

其他设施也遵循同样原则：岗位、空间、资源、电力、物流和受损后果都要实际存在。

# 十二、资源与生产链

## 12.1 首版资源控制在九类以内

为了避免变成复杂工业模拟，垂直切片只保留：

1. 生食。
2. 成品食物。
3. 木材。
4. 废金属。
5. 机械零件。
6. 医疗物资。
7. 普通弹药。
8. 燃料。
9. 特殊材料或蓝图物品。

布料、化学品、火药、皮革等可以在正式扩展阶段加入。

## 12.2 三条主要循环

### 食物循环

狩猎/捕鱼/采集 → 生食 → 厨房或烟熏房 → 成品食物 → 用餐与恢复。

### 建造循环

伐木/搜刮 → 木材与废金属 → 搬运 → 建筑蓝图 → 建造和维修。

### 战斗循环

搜刮零件与弹药 → 维修工坊/弹药间 → 武器、弹药和防御设施 → 夜战消耗 → 次日补充。

## 12.3 物资具有位置

总库存可以在 UI 中汇总显示，但物资实际属于某个仓库或某个角色背包。

结果：

- 东门弹药箱打空，西侧仓库有弹药也不能瞬间共享。
- 厨房离冷藏库太远，会增加搬运时间。
- 大门外死亡的搬运员可能把重要零件掉在地上。
- 仓库被突破后，物资可能损坏或无法使用。

这使基地布局与物流真正影响战斗。

# 十三、建造与维修

## 13.1 建造流程

1. 玩家放置蓝图。
2. 系统检查路径、门、地形和资源需求。
3. 蓝图生成搬运任务。
4. 搬运工把材料送到施工点。
5. 建筑工进行真实施工动作。
6. 完成后设施进入可用状态。

没有资源时蓝图保留，但不会凭空推进。

## 13.2 网格与自由度

推荐使用网格吸附而不是完全自由建造：

- 围墙、门、路障按小网格连接。
- 房间使用 2×2、2×3、3×3 等模块。
- 工作台在房间内部使用预设插槽或较粗网格。

这样可以保证：

- NPC 寻路可靠。
- 第一人称室内不会出现过窄缝隙。
- 敌群能理解墙、门和缺口。
- AI 生成代码更容易维护。

## 13.3 路径验证

放置建筑时必须检查：

- 是否封死基地唯一出口。
- 岗哨是否有可达路径。
- 墙后是否保留维修空间。
- 内层人员是否有撤退路线。
- 大门是否有足够通行宽度。

## 13.4 受损与维修

设施有：

- 结构耐久。
- 功能耐久。
- 火灾或短路状态。

结构耐久低会倒塌；功能耐久低可能仍站立但停产。维修消耗材料和时间，不能只靠一个全局按钮瞬间恢复。

# 十四、战斗与敌人

## 14.1 武器类别

首版建议六类：

- 手枪：轻便、可靠、适合医护与工人。
- 冲锋枪：近中距离控群，耗弹快。
- 霰弹枪：门口击退和近距离爆发。
- 突击步枪：通用主力。
- 栓动或半自动步枪：远距精确和特殊目标。
- 轻机枪/固定机枪：持续压制，依赖补给和岗位。

近战工具保留为紧急手段，不把首版做成完整近战动作游戏。

## 14.2 俯视战斗

当前受控幸存者使用 WASD 移动，鼠标控制朝向和目标。

两种射击方式可并存：

- 默认辅助射击：在准星扇区内选择目标，适合大量敌人。
- 按住精准瞄准：降低移动速度，允许指定目标和弱点。

这样既有幸存者类游戏的直接节奏，也保留玩家技术表达。

## 14.3 第一人称战斗

第一人称提供：

- 更精确的弱点命中。
- 真实弹匣与后坐力表现。
- 固定武器操作。
- 近距离维修、拖拽和拾取。

第一人称不另做独立伤害、武器和背包系统。

## 14.4 敌人类型

### 游荡者

数量最多，移动慢，用于消耗弹药和墙体。

### 奔袭者

速度快，优先追击孤立人员和迟归者。

### 攀爬者

能越过低墙和路障，迫使玩家设置内层守卫。

### 破墙者

高生命、高结构伤害，是精确射手和重武器的主要目标。

### 尖啸者

远处增强周边敌人或召来增援，必须优先击杀。

### 喷吐者

远程攻击岗哨和密集人员，迫使射手移动。

### 潜伏者

白天藏在废墟和副本内，擅长伏击搜刮队。

首版只实现其中四种，验证战术差异后再扩展。

## 14.5 夜间威胁预算

每晚敌人强度由可理解的因素构成：

`夜间威胁 = 基础天数成长 + 人口规模 + 基地噪声 + 灯光与广播 + 未清理巢穴 - 侦察与区域控制修正`

玩家可以看到大致来源，例如：

- 人口增加：+12 威胁。
- 白天大量枪声：+8 威胁。
- 北部巢穴未清理：北侧敌群增加。
- 关闭广播：减少招募机会，也降低威胁。

敌人不是因为玩家墙更强就无条件数值膨胀，而是通过世界状态形成压力。

## 14.6 敌群路径

- 普通敌群使用流场趋向可达的噪声源、入口和薄弱区。
- 破墙者可以主动攻击墙体。
- 攀爬者忽略部分低级障碍。
- 特殊敌人根据职责选择目标。

外墙出现缺口后，流场必须实时更新，敌群自然涌入，而不是继续攻击已经不存在的墙。

# 十五、招募与长期成长

## 15.1 招募来源

- 白天在废墟发现。
- 副本中救出。
- 广播收到求救。
- 流浪者主动接近基地。
- 友好据点交换或请求帮助。
- 敌对团体成员投降。

## 15.2 招募不是无条件增长

新成员需要：

- 床位。
- 食物。
- 基础装备。
- 岗位。
- 社区接纳或任务条件。

人口越多，生产和防御越强，但：

- 消耗提高。
- 休息空间不足。
- 噪声与光照增加。
- 夜间威胁上升。
- 指挥和物流压力变大。

## 15.3 技术解锁

不建议只靠抽象研究点。

技术来源：

- 找到蓝图。
- 招募具备专业知识的人。
- 拆解特殊设备。
- 清理特定副本。
- 对现有设施进行实际升级。

例如没有电工时，玩家即使找到电网门蓝图，也只能建出低效版本或无法维护。

## 15.4 七日节奏

每晚都有攻击，但每七天形成一个明显章节：

- 第 1—2 天：建立基本食物与围墙。
- 第 3—4 天：开放第一处副本和新的幸存者。
- 第 5 天：两个方向同时受压。
- 第 6 天：明显预警，集中准备。
- 第 7 天：大型尸潮、精英或首领。

完成后解锁新区域和更高层设施，而不是把所有系统一次堆给玩家。

# 十六、界面与操作

## 16.1 白天 HUD

持续显示：

- 昼夜时钟与黄昏倒计时。
- 人口与外勤人数。
- 食物、材料、弹药、医疗和电力摘要。
- 当前受控幸存者状态。
- 四到六个高优先级警报。

不在屏幕四周堆满大型面板。详细岗位、库存和人物信息通过侧边抽屉打开。

## 16.2 幸存者列表

每个头像显示：

- 当前岗位。
- 所在区域。
- 生命、疲劳和背包占用。
- 是否遇敌。
- 预计返程时间。

点击头像：镜头跳转。

双击或快捷键：切换为当前可控角色。

## 16.3 工作区界面

玩家选择一个岗位后，在地图上：

- 框选工作区域。
- 选择允许资源。
- 设置最大人数。
- 设置风险阈值。
- 设置返程时间。
- 指定卸货仓库。

## 16.4 夜战 HUD

重点显示：

- 各防区压力。
- 墙体和大门状态。
- 前线弹药。
- 电力。
- 倒地与救援请求。
- 特殊敌人标记。

命令模式打开后显示防区线、射界、撤退点和预备队路线。

## 16.5 建议基础操作

- WASD：控制当前人物移动。
- 鼠标：朝向和目标。
- 左键：射击或确认命令。
- 右键：精准瞄准/命令移动。
- 1—4：职业技能或消耗品。
- Tab：幸存者列表或轮换。
- F：俯视与第一人称切换。
- 空格：战术慢速与命令模式。
- R：换弹。
- E：交互、维修、救援。
- B：建造。
- M：区域地图与工作区。

# 十七、一个完整游戏日示例

## 06:00 黎明

基地有八名幸存者：猎人、渔夫、机械师、急救员、厨师、警员、木匠和搜刮专家。

昨夜东门受损，弹药不足，食物只够两天。玩家决定：

- 机械师优先修东门。
- 木匠和警员负责搬材料与建第二道内门。
- 猎人去北部林区。
- 渔夫去西侧河岸。
- 厨师处理剩余食材。
- 急救员治疗警员的伤势。
- 搜刮专家暂时待命，稍后与玩家下副本。

## 07:10

猎人从工具库拿走步枪、20 发弹药、猎刀和背包，离开北门。渔夫带鱼竿和篮筐从西门出去。机械师从仓库搬取废金属，实际走到东门开始维修。

## 08:30

猎人发现鹿群，但附近有两只感染者。系统提示“北部猎人遭遇低级威胁”。玩家选择让他自行处理。猎人击杀感染者，枪声提高北部局部噪声。

## 09:20

玩家带搜刮专家和急救员进入山洞副本。急救员离开医务室，因此基地中受伤的警员只能缓慢恢复。

## 11:00

副本内找到发电设备蓝图和一台重型电机。电机无法放入背包，玩家将其标记为“后续搬运”。与此同时，主世界中的渔夫已经捕获数条鱼，背包 65%。

## 13:40

机械师修好东门后自动转向高优先级任务：维修固定机枪。木匠完成内门框架，但缺少 12 单位废金属。

搜刮专家在副本中受伤。玩家必须决定继续深入找药品，还是提前撤离。

## 15:20

第一次黄昏警告。猎人距离基地较远，系统预计 17:10 返回；渔夫预计 16:20 返回。玩家命令猎人立即返程，并丢弃一部分低价值骨料以提高速度。

## 16:30

玩家小队离开山洞。急救员现场处理搜刮专家的伤势。基地报告北部发现敌群移动迹象。

## 17:10

渔夫回到基地，鱼被送进厨房。猎人仍在北门外。大门策略被设置为“接应迟归人员”。警员和木匠进入北门掩护位。

## 17:35

猎人带着肉和皮跑回基地，身后有数只奔袭者。玩家俯视下令北门集火，随后第一人称接管警员击杀最前方敌人。猎人进门后，大门关闭。

## 18:00 夜幕

所有居民按照预案进入岗位：

- 猎人上北塔。
- 警员守北门。
- 机械师在东门维修组。
- 木匠进入机动封堵组。
- 急救员到内层救护点。
- 搜刮专家因伤留在安全区。
- 厨师担任弹药搬运员。
- 渔夫持霰弹枪守西墙。

## 20:00 主攻

东侧破墙者出现。玩家命令北塔猎人转为“优先特殊目标”，同时调木匠去东门放置临时路障。机械师冒险维修大门，玩家第一人称接管固定机枪压制敌群。

## 22:30 破口

西墙被攀爬者突破。玩家下令西区撤到内门，机动队增援。渔夫倒地，急救员前往拖回。基地没有立刻失败，而是转入内层防御。

## 00:00 战斗结束

玩家查看伤亡、修理需求和实际剩余弹药。白天的每一个决定都在夜里显现：

- 带走急救员使警员恢复不完全。
- 猎人迟归制造北门危机。
- 修好的东门撑过了破墙者。
- 未完成的内门仍然为西侧撤退争取了时间。

这就是本作应当反复产生的故事。

# 十八、首个垂直切片范围

## 18.1 必须实现

### 世界

- 一张约 300×300 米持续主地图。
- 一座可扩建小型基地。
- 一个森林狩猎区。
- 一个河岸鱼点。
- 两处浅层废墟。
- 一个山洞副本入口。

### 幸存者

- 6 名可持续存在的幸存者。
- 4 个明确职业：猎人、机械师、急救员、警员。
- 另外 2 人使用通用工人模板。
- 每人有属性、技能、武器、背包、伤势、疲劳、白天岗位和夜间战位。

### 白天岗位

- 狩猎。
- 钓鱼。
- 搜刮。
- 搬运。
- 建造。
- 维修。
- 烹饪。
- 治疗。

### 基地

- 指挥中心。
- 宿舍。
- 仓库。
- 厨房。
- 医务室。
- 维修工坊。
- 围墙。
- 大门。
- 射击平台。
- 前线弹药箱。

### 战斗

- 俯视控制。
- 第一人称接管。
- 4 类武器。
- 4 类敌人。
- 一次完整夜间尸潮。
- 防区、预备队、维修和救援命令。

### 副本

- 一处山洞内部。
- 真实背包和弹药。
- 全局时钟继续。
- 主世界 NPC 在副本期间继续运行。
- 黄昏前撤离压力。

### 存档

- 保存时间、人物、岗位、库存、建筑、资源点、任务和伤势。

## 18.2 暂时不做

- 车辆。
- 多人联机。
- 大型开放世界。
- 复杂人际关系、恋爱和派系政治。
- 农业季节系统。
- 完整天气灾害。
- 大规模敌对人类战争。
- 50 名以上居民。
- 随机生成无限副本。
- 完整潜行和近战动作树。

## 18.3 垂直切片验收标准

1. 猎人能从基地领装备，走到森林，真实狩猎，把肉装进背包，再走回厨房或仓库。
2. 渔夫能在鱼点工作，受到攻击时请求支援或撤退。
3. 玩家进入山洞后，基地和外勤 NPC 仍继续工作。
4. 黄昏时外勤人员会根据真实距离返程，不传送。
5. 夜晚所有人自动进入战位并自主射击。
6. 玩家能够对防区下令，而不是只能亲自射击。
7. 玩家能第一人称接管任意基地幸存者，退出后该 NPC 恢复原岗位。
8. 墙被突破后，敌人从真实缺口进入，预备队和内层防线生效。
9. 弹药、维修材料和医疗品真实消耗。
10. 一轮 18—22 分钟能够完整形成“白天准备—副本取舍—黄昏返程—夜间防守—战后损失”的闭环。

# 十九、Three.js 技术架构

## 19.1 推荐技术栈

- Vite。
- TypeScript strict。
- Vanilla Three.js。
- DOM/CSS HUD 与菜单。
- Rapier 只用于玩家、少量关键刚体和必要碰撞。
- IndexedDB 或封装后的本地存档。
- GLB/glTF 2.0 作为模型交付格式。

## 19.2 模拟层必须独立于渲染层

Three.js 的 Mesh、Object3D 和 AnimationMixer 不能成为游戏状态真源。

模拟层保存：

- 人物位置和状态。
- 岗位与任务。
- 背包与仓库。
- 资源点。
- 建筑耐久。
- 敌人状态。
- 时间与天气。
- 副本队伍。

渲染层只根据模拟状态创建和更新模型、动画、灯光、粒子和镜头。

## 19.4 NPC AI：两层结构

不建议一开始使用复杂 GOAP。

采用：

### 上层任务选择

`JobPlanner` 根据以下因素给任务评分：

- 玩家优先级。
- 职业与技能匹配。
- 距离。
- 工具与背包是否满足。
- 疲劳和伤势。
- 区域危险。
- 截止时间。

### 下层动作状态机

白天状态：

```text
Idle
→ AcquireEquipment
→ TravelToTarget
→ Work
→ CollectOutput
→ ReturnToBase
→ DepositItems
→ RestOrNextJob
```

异常状态：

```text
Threatened
InCombat
Retreating

```

夜晚状态：

```text
MoveToPost
Guard

```

## 19.5 导航

基地可动态建造，因此首版推荐统一导航网格，而不是完全依赖静态 NavMesh。

- 幸存者：A* 路径。
- 大群敌人：面向基地目标的流场。
- 局部避让：简单分离与短距离转向。
- 建筑放置、墙体摧毁和大门开闭时，更新受影响网格区域。
- 副本可以使用独立导航网格或预烘焙 NavMesh。

## 19.6 全模拟与低频模拟

### 玩家附近或当前场景

- 完整路径、动画、感知、战斗和碰撞。
- 固定 30Hz 游戏模拟。
- 最高 60Hz 渲染并插值。

### 远离镜头的 NPC

- 保留实际位置、路线节点、速度、背包和工作进度。
- 以 2—5Hz 更新宏观移动和任务。
- 只有遇敌、到达、工作完成、受伤等关键事件才提升模拟精度。

### 玩家进入副本后

- 卸载或冻结主世界渲染对象。
- 主世界模拟以低频继续。
- 依据 NPC 的真实路线和当前状态推进，不重新抽取一次“任务结果”。
- 发生重大事件时发送无线电提示；地下无信号时只记录，玩家离开后收到。

这套“双层模拟”是本项目最重要的技术基础。

## 19.7 敌群性能

- 普通敌人大量使用 InstancedMesh。
- 动画采用少量共享动画状态和距离 LOD。
- 子弹优先使用射线命中，只有榴弹和少量慢速武器使用实体抛射物。
- 血迹、弹壳、伤害数字和尸体全部对象池化。
- 远处敌人降低动画和思考频率。
- 只有玩家、幸存者、精英和关键物件使用完整物理刚体。

垂直切片目标可设为：

- 6—12 名幸存者。
- 同屏 150—250 名普通感染者。
- 4—8 名特殊感染者。
- 桌面浏览器稳定接近 60 FPS；低配模式保持 30 FPS 可玩。

## 19.8 数据驱动

幸存者、职业、设施、工作、武器和敌人应使用 JSON 或 TypeScript 配置，而不是散落在场景代码中。

示例：

```ts
interface JobDefinition {
  id: string;
  category: 'field' | 'base' | 'defense';

  requiredTools: string[];

interface SurvivorState {

```

## 19.9 存档边界

存档保存模拟状态，不保存 Three.js 对象。

必须保存：

- 当前天数和时间。
- 所有幸存者的位置、岗位、状态和装备。
- 所有仓库和背包。
- 建筑位置、耐久和工作队列。
- 资源点储量。
- 已侦察区域。
- 当前副本状态。
- 夜间威胁和未清理巢穴。
- 正在执行的路径与任务。

存档需要版本号和迁移函数，避免后续新增字段导致旧档报废。

# 二十一、交给 Grok Build 的执行纪律

每次只允许完成一个里程碑，并要求它：

1. 先阅读现有架构和数据模型。
2. 先写验收测试与调试面板。
3. 不重写已经工作的系统。
4. 模拟状态不得存入 Mesh 或 DOM。
5. 不使用随机定时器伪装 NPC 工作结果。
6. 每个外勤任务必须包含路径、工具、背包、工作和返程。
7. 每个夜间 NPC 必须有岗位、目标规则、弹药和撤退条件。
8. 新功能完成后必须提供可复现的测试步骤。
9. 遇到范围外需求记录到 backlog，不提前实现。
10. 未通过当前里程碑验收，不进入下一阶段。

# 二十二、最终设计判断

这款游戏最有价值的不是“系统多”，而是三件事形成同一条因果链：

**白天，每个人真实地为基地工作；黄昏，每个人必须真实地回来；夜晚，每个人在玩家的计划下真实地承担后果。**

玩家白天看见猎人走出北门、渔夫坐在河岸、机械师修复昨夜的大门；夜晚又看见这些具体的人拿起各自的武器，站到他们被分配的位置。此时幸存者才不是卡牌、人口或炮塔，而是真正需要保护、培养和使用的共同体成员。

副本、建造、第一人称和尸潮都应服务于这一核心，而不是各自长成一套独立游戏。

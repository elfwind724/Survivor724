# 09 垂直切片

## 必须实现（全项目，不是当前里程碑）

### 世界

一张约 300×300 米持续主地图、一座可扩建小型基地、一个森林狩猎区、一个河岸鱼点、两处浅层废墟、一个山洞副本入口。

### 幸存者

6 名可持续存在的幸存者。4 个明确职业：猎人、机械师、急救员、警员。另外 2 人用通用工人模板。每人有属性、技能、武器、背包、伤势、疲劳、白天岗位和夜间战位。

### 白天岗位

狩猎、钓鱼、搜刮、搬运、建造、维修、烹饪、治疗。

### 基地

指挥中心、宿舍、仓库、厨房、医务室、维修工坊、围墙、大门、射击平台、前线弹药箱。

### 战斗

俯视控制、第一人称接管、4 类武器、4 类敌人、一次完整夜间尸潮、防区/预备队/维修/救援命令。

### 副本

一处山洞入口、8–12 节点图、真实背包和弹药、全局时钟继续、黄昏前撤离、用今天的枪守夜。

### 存档

保存时间、人物、岗位、库存、建筑、资源点、任务和伤势。

## 暂时不做

车辆、多人联机、大型开放世界、复杂人际关系与派系政治、农业季节、完整天气灾害、大规模敌对人类战争、50 名以上居民、随机无限副本、完整潜行和近战动作树。

## 当前验收

1. **进本**：走到发光山洞，刷 8–12 节点图。
2. **对比**：C 打开人物面板，看出哪把枪更强并换上。
3. **撤离**：天黑前从 exit 出本，东西在真实背包里。
4. **守夜**：用今天换上的枪上岗射击。

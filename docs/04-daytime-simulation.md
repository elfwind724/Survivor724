# 04 白天模拟

## 外勤岗位怎么工作

### 狩猎

不是点击资源点读条。鹿类逃跑，野猪受伤后冲锋，小型动物噪声小，掠食动物可能袭击孤立 NPC。枪声提高局部噪声，可能增加该方向夜间威胁。

产出：生肉、兽皮、骨料。需要猎枪/弓弩、猎刀、后期陷阱和大背包。

### 钓鱼

浅水安全低产，深水高产需更好渔具，污染水域有疾病风险。鱼竿慢，渔网两人高产，捕鱼笼布置后收取。渔夫长时间静止，容易被偷袭。鱼必须尽快送厨房、烟熏房或冷藏库。

### 浅层废墟搜刮

与主世界无缝存在。流程：清理周边 → 检查入口 → 搜索容器 → 拆取材料 → 装入背包 → 标记已搜区域 → 返程。

发电机、金属箱、机械部件不能直接变背包数字，需要两人搬运、推车、后期车辆，或先标记再派搬运队。

### 伐木、采集、拆解

同样走「前往—工作—装载—返程—卸货」。伐木噪声高。

## 玩家为什么还要亲自外出

NPC 负责稳定资源。玩家负责清危险区、取蓝图和稀有部件、救援、击杀精英、开启新区、进副本、处理 NPC 无法解决的危机。

## 黄昏返程不是传送

NPC 根据路线距离和移动速度计算能否按时回基地。地图用绿/黄/红表示预计安全、可能迟到、无法在夜幕前到达。

玩家可下令：立即返程、做完当前工作再走、丢弃负重、去最近安全屋、请求护卫、坚持工作。

迟归者继续沿已知安全路线走，遇敌躲避或战斗，可能丢负重逃生。不会瞬间死亡，也不会自动传回。

## 黄昏战备

返回后自动：卸采集物 → 补弹药医疗 → 换夜战装备 → 去夜间战位 → 维修队检查 → 医护建救护点 → 弹药员填前线箱 → 大门按计划关闭。

## 首版资源不超过九类

1. 生食
2. 成品食物
3. 木材
4. 废金属
5. 机械零件
6. 医疗物资
7. 普通弹药
8. 燃料
9. 特殊材料或蓝图物品

三条循环：

- 食物：狩猎/捕鱼/采集 → 生食 → 厨房或烟熏 → 用餐恢复
- 建造：伐木/搜刮 → 木材与废金属 → 搬运 → 蓝图施工
- 战斗：零件与弹药 → 工坊 → 武器弹药防御 → 夜战消耗 → 次日补充

## 物资具有位置

UI 可以汇总显示，但物资实际属于某个仓库或某个角色背包。

- 东门弹药箱打空，西侧仓库的弹药不能瞬间共享
- 厨房离冷藏库太远会增加搬运时间
- 大门外死亡的搬运员会把零件掉在地上
- 仓库被突破后物资可能损坏或无法使用

# 项目目标

这是一个 Three.js 3D 俯视生存游戏。
核心是幸存者持续模拟、基地建设、白天工作、玩家副本探索和夜间尸潮指挥。

# 不可违反的玩法原则

1. NPC 外出工作时必须真实存在于世界中，不得使用派遣后随机返回资源的机制。
2. 玩家进入副本后，基地和外部 NPC 仍继续低频模拟。
3. 夜间 NPC 负责自主战斗，玩家负责防区、增援、撤退和集火指令。
4. 第一人称只能接管现有幸存者，不创建独立角色或独立战斗数据。
5. 资源必须存在于容器、背包、地面或仓库中，不得无来源地进入全局数字。
6. 建筑必须经历蓝图、材料搬运和施工过程。
7. 不得未经批准增加新的大型系统。

# 技术原则

1. 模拟层与 Three.js 渲染层分离。
2. Mesh 不得保存核心游戏规则。
3. 使用固定时间步更新模拟。
4. HUD 和复杂菜单使用 DOM。
5. 重复敌人优先使用 InstancedMesh 和对象池。
6. 普通枪械优先使用射线命中。
7. 所有系统必须保持 TypeScript 严格类型。
8. 每个阶段完成后必须执行类型检查和生产构建。

# 当前开发阶段

当前只允许开发 GDD M0：架构骨架和 NPC 工作闭环。
不得提前制作完整尸潮、完整副本或大量美术资产。
不要复制旧公路游戏的 Manager 架构。

# 08 界面与操作

HUD 和复杂菜单使用 DOM。不要把岗位面板、库存、人物详情塞进 WebGL。

## 白天 HUD

持续显示：

- 昼夜时钟与黄昏倒计时
- 人口与外勤人数
- 食物、材料、弹药、医疗和电力摘要
- 当前受控幸存者状态
- 四到六个高优先级警报

详细岗位、库存和人物信息用侧边抽屉。不要在屏幕四周堆满大型面板。

## 幸存者列表

每个头像显示：当前岗位、所在区域、生命、疲劳、背包占用、是否遇敌、预计返程时间。

- 单击：镜头跳转
- 双击或快捷键：切换为当前可控角色

## 工作区

选择岗位后，在地图上框选区域、选择允许资源、设置最大人数、风险阈值、返程时间和卸货仓库。

## 夜战 HUD

重点：各防区压力、墙体大门、前线弹药、电力、倒地与救援、特殊敌人标记。命令模式显示防区线、射界、撤退点和预备队路线。

当前已接通：WASD 移动，单击开枪（接管中且未选建造）。俯视左键拖移、右键转镜头、滚轮缩放。左下角建造菜单选设施。T 切换 2× 时间，] 快进 60 秒。走近倒地的鹿会自动剥肉。

## 基础操作

| 按键 | 作用 |
|---|---|
| WASD | 当前人物移动 |
| 鼠标 | 朝向和目标 |
| 左键 | 射击或确认命令 |
| 右键 | 精准瞄准 / 命令移动 |
| 1–4 | 职业技能或消耗品 |
| Tab | 幸存者列表或轮换 |
| F | 俯视与第一人称切换 |
| 空格 | 战术慢速与命令模式 |
| R | 换弹 |
| E | 交互、维修、救援 |
| B | 建造 |
| M | 区域地图与工作区 |

第一人称只接管现有幸存者。不要为第一人称创建第二套操作角色。

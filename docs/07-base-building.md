# 07 基地建造

## 建造流程

1. 玩家放置蓝图
2. 系统检查路径、门、地形和资源需求
3. 蓝图生成搬运任务
4. 搬运工把材料送到施工点
5. 建筑工进行真实施工动作
6. 完成后设施进入可用状态

没有资源时蓝图保留，但不会凭空推进。禁止一键瞬间建成。

## 网格

使用网格吸附，不要完全自由建造。

- 围墙、门、路障按小网格连接
- 房间使用 2×2、2×3、3×3 等模块
- 工作台在房间内部使用预设插槽或较粗网格

目的：NPC 寻路可靠，第一人称室内没有过窄缝隙，敌群能理解墙门缺口。

## 路径验证

放置时必须检查：

- 是否封死基地唯一出口
- 岗哨是否可达
- 墙后是否保留维修空间
- 内层人员是否有撤退路线
- 大门是否有足够通行宽度

## 受损与维修

设施有结构耐久、功能耐久、火灾或短路状态。结构耐久低会倒塌；功能耐久低可能仍站立但停产。维修消耗材料和时间。

## 设施必须有空间、岗位、输入、输出和工作动作

设施不是「每小时 +5」。以厨房为例：

- 没有厨师：只能保存少量生食
- 普通人员：能做基础餐，浪费原料
- 专业厨师：提高产量，解锁强化餐
- 没有清水：产量下降并有疾病风险
- 没有冷藏：原料腐坏
- 夜晚被突破：可能起火，次日全体恢复受影响

垂直切片必须包含：指挥中心、宿舍、仓库、厨房、医务室、维修工坊、围墙、大门、射击平台、前线弹药箱。

完整设施表见源文档第十一章。仓储位置决定搬运距离；军械库过远会断夜战火力；冷藏库需要电力。

## 电力与物流

发电机和后期太阳能/风力提供容量。停电会影响冷藏、照明、电网门和部分生产。物流是玩法：谁搬、从哪搬到哪、路是否被堵，都必须是模拟事实。
